# ماه من | MAH-E MAN

A Persian, right-to-left romantic countdown and letter experience for Mahdieh, made by Mojtaba.

## Website files and folders

The three editable website sources are:

- `index.html` — semantic HTML and the five scenes
- `style.css` — responsive styling, typography, illustrations, and motion
- `script.js` — Tehran-time countdown, scenes, music, notification reminder, and local test controls

Assets are grouped separately:

```text
assets/
  icon.svg                 # Website/PWA icon and source artwork
  icons/                   # 192px and 512px PWA icons
  android/                 # Generated launcher and notification icon resources
font/                     # Vazirmatn, its license, and optional Doran font
audio/                    # Optional music file (see below)
```

`www/` and `android/` are generated by the Capacitor build and ignored by Git, except the tracked `www/font/` placeholder (and an optional Doran file) retained for compatibility. The root `font/` folder is the simpler place for new fonts; do not edit other generated copies.

## Local preview and test mode

Run a static server from the repository root, for example:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Open `http://localhost:8000/`. The countdown is based on **11 October 2026 at 00:00 in `Asia/Tehran`**, converted with the browser's IANA time-zone database (no hard-coded offset). As with any static client-side page, the device clock and local storage are not a trusted security boundary; this protects against accidental early display, not intentional tampering.

To preview every scene without waiting, temporarily change `APP_CONFIG` near the top of `script.js` to:

```js
environment: "development",
enableDeveloperTools: true,
```

Keep the target settings below it unchanged and open the page on `localhost`. A local-only panel previews waiting, the final countdown, reveal, letter, and ending using the same rendering/state code. Test progress is kept out of production storage. Restore `environment: "production"` and `enableDeveloperTools: false` before publishing. A query parameter cannot enable this mode.

## Icon

`assets/icon.svg` is the master moon-and-heart mark. The PWA icon sizes are under `assets/icons/`; Android launcher and notification icons are under `assets/android/`. Both deployment workflows package these assets.

## Fonts

The root `font/` folder contains the licensed Vazirmatn Arabic/Persian and Latin WOFF2 subsets. Add your licensed Doran WOFF2 file as **`font/Doran.woff2`**. The existing Capacitor upload slot **`www/font/Doran.woff2`** is also supported for compatibility. Pages and Android package either location; the page switches to Doran when the file loads and otherwise uses Vazirmatn. Keep the actual file extension and format accurate.

## Music

There is **no song included yet**. The existing sound button plays quiet synthesized chimes after a tap; it is not a music track. To add optional music, place your licensed MP3 at **`audio/song.mp3`**. The music button appears only when that file exists, and playback starts only after the user taps it—mobile browsers block reliable autoplay. The website and APK workflows copy supplied audio files into the build.

## Notifications

The waiting screen offers an **Enable notification** button. The phone's permission prompt appears only after the visitor taps it; if granted, Android schedules one local reminder for the countdown target. It uses Capacitor's local-notifications plugin, so it does not need a push server. The Android reminder is deliberately scheduled without asking for special exact-alarm access; battery/background restrictions can still shift its delivery time slightly. In a normal browser, permission is requested too, but its timer only works while the page stays open; reliable reminders after closing the page are provided by the Android app, not the static website. This is a local reminder, not remote push messaging.

## GitHub Pages

`.github/workflows/pages.yml` packages the three root source files, bundles the notification bridge with esbuild, and adds icons, fonts, and any supplied music. The repository had no configured Pages site at inspection time. Set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**; a push to `main` then runs the Pages workflow. The manifest supports standalone display mode. No service worker or web push service is included.

## Android APK via GitHub Actions

`capacitor.config.json` points Capacitor at the generated `www/` bundle. `.github/workflows/android-apk.yml` stages the website and assets, bundles the Local Notifications plugin, generates the Android project on the GitHub runner, builds a debug APK, and uploads **`MAH-E-MAN-android-debug`**. The workflow runs on pushes to `main` or the Arena branch and can also be started manually from the repository's **Actions** tab. The generated `android/` project is intentionally not checked in; Capacitor and its plugins are version-pinned in `package.json`/`package-lock.json`.

The APK is debug-signed for testing, not a Play Store release. The Android launcher icon and small notification icon are customized from `assets/android/`.
