# ماه من | MAH-E MAN

A Persian, right-to-left romantic countdown and letter experience for Mahdieh, made by Mojtaba.

## Website files and folders

The three editable website sources are:

- `index.html` — semantic HTML and the five scenes
- `style.css` — responsive styling, typography, illustrations, and motion
- `script.js` — Tehran-time countdown, scenes, music, notification reminder, and local test controls

Assets are grouped separately:

```text
assets/
  icon.svg                 # Website/PWA icon and source artwork
  icons/                   # 192px and 512px PWA icons
  android/                 # Generated launcher and notification icon resources
font/                     # Vazirmatn, its license, and optional Doran font
audio/                    # Optional music file (see below)
```

`www/` and `android/` are generated by the Capacitor build and ignored by Git, except the tracked `www/font/` placeholder (and an optional Doran file) retained for compatibility. The root `font/` folder is the simpler place for new fonts; do not edit other generated copies.

## Local preview and test mode

Run a static server from the repository root, for example:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Open `http://localhost:8000/`. A 15-second animated intro leads into the minimal, orbital home scene. The countdown is based on **11 October 2026 at 00:00 in `Asia/Tehran`**, converted with the browser's IANA time-zone database (no hard-coded offset); the displayed seconds round up and the timer resynchronizes on foreground/focus. Continuous canvas animation is limited to the moments that need it, keeping the countdown responsive without a busy background loop. As with any static client-side page, the device clock and local storage are not a trusted security boundary; this protects against accidental early display, not intentional tampering.

To preview every scene without waiting, temporarily change `APP_CONFIG` near the top of `script.js` to:

```js
environment: "development",
enableDeveloperTools: true,
```

Keep the target settings below it unchanged and open the page on `localhost`. A local-only panel previews waiting, the final countdown, reveal, letter, and ending using the same rendering/state code. In production, tap the nearly invisible star at the lower-right edge and enter **1592** to open the same test panel; choose a scene, then lock the panel to return to the real timer. This is a client-side testing shortcut, not a security feature, and test progress is never written to production storage. Restore `environment: "production"` and `enableDeveloperTools: false` before publishing. A query parameter cannot enable this mode.

## Icon

`assets/icon.svg` is the master lunar seal: a luminous crescent, a heart-centered star, and fine orbital rings. The PWA icon sizes are under `assets/icons/`; Android launcher and notification icons are under `assets/android/`. Both deployment workflows package these assets.

## Fonts

The root `font/` folder contains Vazirmatn Arabic/Persian and Latin WOFF2 subsets plus Doran at **`font/Doran.woff2`**. The compatibility upload slot **`www/font/Doran.woff2`** is also supported; both files are currently preserved. Pages and Android package either location. The page uses Doran when it loads and otherwise falls back to Vazirmatn. Keep the actual file extension and format accurate.

## Music

The project currently includes a track at **`audio/song.mp3`**. In the installed Android app it attempts to start automatically on launch; the Android WebView is configured to allow that. In an ordinary browser preview, playback remains tap-to-start because browser autoplay policies vary. The separate sound button plays quiet synthesized chimes. To replace the track, use audio you have permission to distribute. The website and APK workflows package the file.

## Notifications

The waiting screen offers an **Enable phone notification** button. It asks for notification permission only after a tap inside the installed Android app; Capacitor Local Notifications checks and requests the real Android system permission, then schedules one native local reminder for the target time. Android 13 and later show the runtime permission dialog; older Android versions may not need one. The reminder is scheduled as non-exact and the app does not ask the user to grant special exact-alarm access, so Android battery/background restrictions can shift delivery slightly. A website preview never shows a browser permission dialog pretending to be phone permission, and it does not schedule a reminder; the reminder is available only in the installed Android app. This is a local notification, not remote push messaging.

## GitHub Pages

`.github/workflows/pages.yml` packages the three root source files, bundles the notification bridge with esbuild, and adds icons, fonts, and any supplied music. The repository had no configured Pages site at inspection time. Set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**; a push to `main` then runs the Pages workflow. The manifest supports standalone display mode. No service worker or web push service is included.

## Android APK via GitHub Actions

`capacitor.config.json` points Capacitor at the generated `www/` bundle. `.github/workflows/android-apk.yml` stages the website and assets, bundles the Local Notifications plugin, generates the Android project on the GitHub runner, builds a debug APK, and uploads **`MAH-E-MAN-android-debug`**. The workflow runs on pushes to `main` or the Arena branch and can also be started manually from the repository's **Actions** tab. The generated `android/` project is intentionally not checked in; Capacitor and its plugins are version-pinned in `package.json`/`package-lock.json`.

The APK is debug-signed for testing, not a Play Store release. The Android launcher icon and small notification icon are customized from `assets/android/`.
